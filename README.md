## Как загрузить файлы с телефона
1. Открой в браузере github.com → свой репозиторий. В меню браузера включи «Версия для ПК».
2. Открой нужную папку (например `www`) → **Add file → Upload files** → выбери файлы из распакованного ZIP → внизу **Commit changes**.
3. Файлы с тем же именем заменятся сами. Для `.github/workflows/` открой папку по очереди: `.github` → `workflows` → Upload files.
4. Файлы корня (`package.json`, `version.json`, `supabase.sql`) загружай со страницы репозитория, не заходя в папки.
ZIP на GitHub не распаковывается — сначала распакуй его на телефоне (Файлы → ZIP → «Извлечь»).

## Как собрать APK
После коммита сборка запускается сама. Либо: вкладка **Actions → Build Paseka APK → Run workflow**.
Через ~5–10 минут открой готовый запуск, внизу блок **Artifacts → Paseka-APK**: скачай, распакуй, установи `Paseka-1.1.0.apk`.

## Общий рейтинг (Supabase, бесплатно) — НЕ обязательно
Без этой настройки игра полностью работает, а «Топ игроков» показывает только твои личные рекорды. Чтобы видеть других игроков, нужна база, около 5 минут без программирования:
1. Зайди на supabase.com → зарегистрируйся → **New project** (имя любое, регион ближайший, придумай пароль БД).
2. Слева **SQL Editor → New query**. Вставь содержимое `supabase.sql` → **Run**. Должно быть «Success».
3. Слева **Project Settings → API**. Скопируй **Project URL** и ключ **anon public**.
4. В GitHub: репозиторий → **Settings → Secrets and variables → Actions → New repository secret**.
   Создай два секрета: `SUPABASE_URL` (вставь Project URL) и `SUPABASE_KEY` (вставь anon public key).
5. Запусти сборку заново (Actions → Run workflow) и установи новый APK.
Важно: ключ anon public предназначен для приложений, но он виден внутри APK. Опытный игрок может подделать свои цифры в рейтинге.

## Обновления игры
- Игра при запуске читает `version.json` из твоего репозитория (адрес подставляется сам).
- Выпустил новый APK: в `package.json` поменяй `"version"` (например на 1.3.0) и в `version.json` поменяй `"latest"` на то же число. ВАЖНО: `version.json` с новой версией загружай, только когда APK уже опубликован в Telegram, иначе у игроков появится окно обновления без файла. У старых версий появится окно с кнопкой «Скачать обновление» (откроется https://t.me/pasekagame).
- `"force": true` — окно без кнопки «Позже» (обязательное обновление). `"min": "1.1.0"` — версии ниже обязаны обновиться.
- Менять `version.json` можно без сборки APK: правка файла прямо на GitHub (карандаш ✏️), примерно через 5 минут все игроки увидят её.
- Нет интернета — игра просто запускается без окна. «Позже» скрывает окно для этой версии на 24 часа.
