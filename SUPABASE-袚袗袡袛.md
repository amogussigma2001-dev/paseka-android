# Supabase для «Пасеки»: рейтинг, друзья, подарки, обмен (полный гайд)

Всё делается в браузере телефона, программировать не нужно. Время: около 10 минут. Это бесплатно.

## 0. Что получится, а что нет
**Получится:** общий рейтинг, друзья по коду, заявки в друзья, ежедневный подарок другу (+1 яйцо 🥚), обмен между друзьями (яйца, монеты, мёд, обычные пчёлы).
**Не получится / честно:**
- Покупки 💎 за деньги НЕ подключены (нужен Google Play, это платно). Их здесь нет.
- Игра хранит прогресс на телефоне. Сервер не знает, сколько у игрока предметов, поэтому честность обмена держится на правилах (нельзя принять предложение дважды, лимиты, только друзья), а не на полной проверке. Хитрый игрок с правкой сохранения может подделать предметы. Для небольшой игры это нормальный компромисс; для настоящей защиты нужен сервер, который хранит весь прогресс.
- Вход анонимный: аккаунт привязан к телефону. Если стереть данные игры или переустановить её, будет новый аккаунт и новый код друга (старые друзья пропадут). Резервный код переносит прогресс игры, но не друзей.

## 1. Создай проект
1. Открой supabase.com в браузере, нажми **Start your project**, войди через GitHub или e-mail.
2. **New project**: имя `paseka`, придумай пароль базы (запиши), регион ближайший (например Frankfurt), тариф **Free**. Нажми **Create new project**, подожди 1-2 минуты.

## 2. Включи анонимный вход (без этого ничего не заработает)
1. Слева **Authentication**.
2. Найди раздел **Sign In / Providers** (в старых версиях просто **Providers** или **Settings**).
3. Найди переключатель **Allow anonymous sign-ins** и включи его. Сохрани (**Save**).

## 3. Создай таблицы и функции
1. Слева **SQL Editor** → **New query**.
2. Открой файл `supabase.sql` из проекта «Пасеки», скопируй ВЕСЬ текст, вставь в окно.
3. Нажми **Run**. Должно появиться «Success. No rows returned». Если красная ошибка, пришли мне её текст (скриншот), я исправлю.
(Скрипт можно запускать повторно, ничего не сломается.)

## 4. Возьми два значения
1. Слева **Project Settings** (шестерёнка) → **API** (или **Data API**).
2. Скопируй **Project URL** (вида `https://abcdefgh.supabase.co`).
3. Скопируй ключ **anon public** (длинный, начинается с `eyJ`).
**Никогда не копируй и не отправляй ключ `service_role`:** он даёт полный доступ к базе.

## 5. Добавь их в GitHub
Репозиторий → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**:
- `SUPABASE_URL`: вставь Project URL
- `SUPABASE_KEY`: вставь ключ anon public
(Если секреты уже есть от старого рейтинга, они подходят, менять не нужно.)

## 6. Пересобери APK и проверь
1. **Actions** → **Build Paseka APK** → **Run workflow**, скачай APK, установи.
2. В игре: главное меню → **Друзья**. Должен появиться «Мой код друга» (8 символов). Если видишь ошибку, смотри раздел 7.
3. Поставь игру на второй телефон (или попроси друга). Введи код друга в поле **Добавить друга**, на втором телефоне прими заявку.
4. Проверь: подарок 🎁 (другу придёт яйцо), обмен ⇄ (предложи, на втором телефоне прими).
5. **Топ игроков** покажет всех, кто хоть раз зашёл с интернетом.

## 7. Если не работает
| Что видишь в игре | Причина и решение |
|---|---|
| «нет входа в Supabase» | не включён Allow anonymous sign-ins (шаг 2), либо неверный URL/ключ в секретах |
| «Could not find the function ...» / «permission denied» | не выполнен supabase.sql (шаг 3) или он выдал ошибку |
| «Друзья требуют подключения Supabase» | секреты `SUPABASE_URL`/`SUPABASE_KEY` не заданы, или после их добавления не пересобран APK |
| «Нет связи с сервером» | нет интернета или проект на паузе (бесплатные проекты засыпают после недели без запросов: открой проект на supabase.com и нажми **Restore**) |
| «обмен только с друзьями», «не больше 5 открытых предложений» | это правила обмена, не ошибка |

## 8. Лимиты и безопасность
- Бесплатный тариф: 500 МБ базы, 50 000 активных пользователей в месяц. Для небольшой игры хватает с запасом.
- Анонимные пользователи копятся в Authentication → Users. Можно периодически чистить.
- Если кто-то начнёт массово создавать аккаунты, включи **CAPTCHA** (Authentication → Attack Protection) или напиши мне.
- Обмен только между друзьями, не более 5 открытых предложений и 20 в сутки, 💎, VIP и событийные пчёлы не обмениваются. Подарок другу: один в день на каждого.
- Ключ anon public виден внутри APK. Это нормально: защита держится на правилах в базе (RLS) и функциях из `supabase.sql`, прямая запись в таблицы запрещена.

## 9. Что можно сделать дальше (после твоего подтверждения, что всё работает)
- Серверные проверки в Edge Functions (например, лимиты на суммы обмена по уровню).
- Гильдии и общие события.
- Покупки через Google Play (нужны платный аккаунт разработчика и настройка в Play Console).
Если что-то не заработает, пришли мне скриншот ошибки из игры или из SQL Editor. Ключи и пароли присылать не нужно.
